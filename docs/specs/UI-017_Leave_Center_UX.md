# UI-017｜排假中心 UX 重構（Official）

定位：**3 秒看懂、10 秒完成排假**

## 範圍

- 重構排假中心首頁為月曆總覽＋今日／本月統計
- 日期 Bottom Sheet、單頁新增、批次、搜尋、長按、Today
- 月曆格人力風險燈號（充足／警戒／不足；來自單次 Snapshot）
- **不改**：排班 SoT、權限架構、Supabase Schema、Auth

## 首頁（一次 Snapshot）

`buildLeaveCenterHomeSnapshot()` 單次掃描本月 `leaveRegistry`，供：

- 月曆格：假別 emoji＋人數（最多 3 人份；超出 `+N`；不堆姓名）
- 人力風險：`workforce.level` = good／watch／risk（日格邊框＋警戒／不足標）
- 今日概況：今日休假／今日請假／待審核
- 本月統計：自選休／病假／事假／婚假／喪假／公假

## 互動

| 操作 | 行為 |
|------|------|
| 點日期 | Bottom Sheet：依假別分組名單＋「＋新增排假」 |
| ＋新增／單頁建立 | ①員工 ②日期 ③假別 ④備註 ⑤完成（`compactUi`） |
| 【批次】 | 既有 `openPreLeaveBatch`（多員工／同日／同假別） |
| 搜尋 | 姓名／工號 → 定位日期 |
| 長按／詳情 | 假單資訊；幹部可編輯／取消 |
| 【今天】 | 跳至當月並捲到今日 |
