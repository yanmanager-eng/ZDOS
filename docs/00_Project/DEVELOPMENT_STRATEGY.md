# ZDOS Development Strategy

## Production

來源：現行 ZDOS v1.5.0

使命：
- 完成既定功能
- 修正 Bug
- 驗收
- 穩定發布

允許：
- Bug Fix
- Security Fix
- Performance Fix
- RWD Fix
- UI／UX 小幅修正
- 已核准功能收尾

禁止：
- 大型新模組
- Founder Workspace
- Genesis
- Knowledge Engine
- Decision Engine
- 全新 UI 架構

## Next

名稱：ZDOS Next

使命：
- 在不破壞 v1.5.0 的前提下，研發下一代能力

第一原則：
- 初始版本必須與 v1.5.0 完全一致
- 所有創新必須可關閉
- 不可回寫或污染 Production 工作區
- UI 延續現有 ZDOS 設計語言

核心準則：

Production 守護今天。
Next 創造明天。
